# Fern Client — Releases

Official downloads of **Fern Client**, a fresh all-round client for Minecraft: Java Edition.
Website: **https://fernclient.net**

Go to **[Releases](../../releases)** for:

- **Fern Setup** (`Fern Setup.exe`): installs the Fern Client launcher on Windows 10/11
- **fern-core** jars (`fern-fabric-<mc>-<version>.jar`, `fern-neoforge-<mc>-<version>.jar`): downloaded
  automatically by the launcher, listed here for transparency

Every release lists a **SHA-256** checksum per file. The launcher only installs files whose checksum
matches. To check a download yourself on Windows:

```powershell
Get-FileHash ".\Fern Setup.exe" -Algorithm SHA256
```

This repository contains **no source code**, only release notes and downloads.

You need your own copy of Minecraft: Java Edition. By downloading you agree to the Terms of Service
and have read the Privacy Policy (https://fernclient.net/terms, https://fernclient.net/privacy).
